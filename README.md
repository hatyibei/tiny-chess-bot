A compact, original chess engine written in 4 KB of Python. It searches with negamax alpha-beta and iterative deepening under a fixed node budget, with quiescence, a transposition table, PVS and late-move reductions, and scores positions by material and piece-square tables.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
